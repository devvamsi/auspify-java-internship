# Task 2 – Number Guessing Game

**Intern:** N VAMSI
**Program:** Java Developer Internship – Auspify Technologies
**Date:** 15/10/26
## Description
An interactive Java console game where the computer picks a random
number and the player tries to guess it within limited attempts.

## Features
- Random number generation
- Higher/Lower hints
- Warmth indicator (HOT/WARM/COLD/FREEZE)
- 4 difficulty levels (1-50, 1-100, 1-500, 1-1000)
- Attempt counter + best score tracking
- Rating system based on efficiency
- Play-again loop
- Final statistics (games played, games won, best score)

## Technologies Used
- Java (JDK 8+)
- Loops and Conditional Logic
- java.util.Random
- java.util.Scanner
- Exception Handling (NumberFormatException)

## Files
- NumberGuessingGame.java - Main game

## How to Run
javac NumberGuessingGame.java
java NumberGuessingGame
