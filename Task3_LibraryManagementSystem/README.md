# Task 3 - Library Management System

**Intern:** N Vamsi
**Program:** Java Developer Internship - Auspify Technologies
**Date:** 15/10/26

## Description
A Java console-based application to manage library books with
add/remove, search, issue, and return functionality.

## Features
- Add Book (with duplicate ID check)
- Remove Book (blocked if currently issued)
- View All Books
- View Only Available Books
- Search Book by ID
- Search Book by Title (partial match)
- Issue Book
- Return Book
- Input validation throughout

## Technologies Used
- Java (JDK 8+)
- OOP - Encapsulation
- Collections - ArrayList
- java.util.Scanner
- Exception Handling

## Files
- Book.java - Model class (id, title, author, issued status)
- LibraryManagementSystem.java - Main application

## How to Run
javac Book.java LibraryManagementSystem.java
java LibraryManagementSystem
